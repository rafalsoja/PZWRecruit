# PZWRecruit

Automated recruitment announcement addon for World of Warcraft (Legion 7.3.5 / Tauri WoW).

> **Note**: Tailored for the needs of the **PZW (Polski Związek Wędkarski)** guild.

## Features

* **Sends automated guild-recruitment messages on specified channel :o**


![shocked pikatchu](https://i.imgur.com/tjHgFL5.png)

## Installation

1. Place the `PZWRecruit` folder into `Interface/AddOns/`.
2. Enter `/pzw` ingame to configure the addon.
